# GPT 白龙桌宠合集

本仓库提供 Android 独立桌宠和 Windows Codex 桌宠插件。

## Android 版

支持 Android 9 及以上。下载并安装白龙娘桌宠，打开应用后按提示授权「显示在其他应用上层」，返回应用后点「开启桌宠」。[下载 APK](https://github.com/hyG0611/White-Dragon-Girl-codex-plugin/raw/refs/heads/main/android/DragonPet-Android.apk)

开启后可返回手机桌面或切换到其他应用。轻点白龙娘随机播放互动，拖动调整位置，长按打开菜单，可手动选择全部 25 段动作或关闭桌宠。动画已内置，应用可离线使用，无需登录或打开 ChatGPT。

源码、配套素材和构建步骤见 [Android 目录](android/README.md)。

## Windows 版

Windows 版在同一个本地插件市场中提供两套独立桌宠，共用 Python 环境和 Codex 启动监控。

| 插件 | 功能 |
| --- | --- |
| 白龙娘 `bailong-pet` | 透明 WebP 动画、拖拽、对话气泡、可选工作状态和 Codex 额度展示 |
| DSH 白龙 `dsh-dragon` | MP4 与透明 VP9 WebM、角色切换、同进程多宠、悬停快捷栏、待办提醒、本机 Codex 对话与工作状态联动 |

### 随附素材

仓库包含 25 段白龙娘透明 WebP、DSH 白龙的四段 MP4、大肥鱼的 106 段透明 WebM，以及雏龙娘的 109 段透明 WebM。白龙娘会在本机按需生成播放缓存。

可用 `-VideoSource` 导入额外的 DSH MP4。以 `点击回应` 开头的视频用于点击互动，`被鼠标拖拽悬空反馈.mp4` 用于拖拽动作。素材来源与授权见下方说明。

### 雏龙娘全动作角色包

2026-11-21 新增 Windows 独立角色「雏龙娘」，并修复初版的停帧和突然复位。提示词目录实际包含 109 条（比原先提到的 108 条多「是啊，吃什么」），本次全部覆盖。新版每段 640×360、60 fps、10 秒、600 帧，包含点击互动、工作、额度、节日和睡觉三段。

| 内容 | GitHub 中的位置 | 数量 |
| --- | --- | --- |
| 桌宠使用的透明 VP9 WebM | [雏龙娘角色动画](codex-adapter/plugins/dsh-dragon/assets/characters/雏龙娘/videos) | 109 段 |
| 剪辑使用的绿幕 MP4 | [雏龙娘素材包](materials/雏龙娘/README.md) | 109 段 |
| 新绘插画、关键姿势及制作代码 | [Remotion 制作项目](remotion-materials/README.md) | 19 张图集、438 张姿势图 |
| 动作总览、规格和文件校验值 | [素材目录](materials/雏龙娘) | 完整索引 |

右键桌宠，选择 **切换角色 → 雏龙娘**，再进入 **播放动作（全部素材）** 手动选动作。「睡觉-开始」播放后会进入持续循环，选择「睡觉-起来」后回到待机。

新版把原来的主要插画姿势加密为神经网络中间姿势（常规动作 161 个样本），配合连续的呼吸、摆动和细分运动生成 600 帧，不再在动作头尾长时间停住。挥手和转身样片的相邻重复帧从 49 组降为 0。600 帧包含计算生成的中间画面，不是 600 张重新绘制的插画。

播放器保留透明视频原生帧率，并让循环动画共用 96 MiB 无损压缩缓存。实测同一播放路径约 60 fps，跨越 10 秒循环边界只启动一次解码。复杂动作仍采用二维概括表现，较大姿势变化时可能出现插画形变。[素材来源与说明](codex-adapter/plugins/dsh-dragon/assets/characters/雏龙娘/ASSETS.md)

### 安装

需要 Windows、已安装的 Codex 桌面版，以及带 Tk 的 Python 3.11 或更高版本。在仓库根目录运行 PowerShell，并替换示例中的本地路径。

```powershell
cd codex-adapter
.\install.ps1 -PythonPath 'D:\python\python.exe'
```

默认安装两个插件。只安装白龙娘时，可传入 `-Plugins bailong-pet` 。如果无法自动定位 Codex CLI，可用 `-CodexPath` 指定可执行文件的绝对路径。

安装脚本会创建隔离 Python 环境、注册本地市场 `bailong-local`，并创建或更新当前用户的登录启动快捷方式。后台监控在检测到 Windows Store 版 Codex 打开时启动所选桌宠，在 Codex 完全退出时关闭桌宠。工作状态 hooks 可在 Codex 中审阅后启用。

### 悬停快捷栏

右键点击 DSH 桌宠，打开「切换角色」，选择 **默认白龙**、**雏龙娘**或**大肥鱼**。三个角色的操作相同。把鼠标停在角色身上，快捷栏会出现在旁边。将鼠标移到栏上后，点击所需的按钮。

- **对话**打开快捷对话窗口，输入消息后按 Enter 发送。点「完整对话」可进入聊天窗口，在那里打开「模型设置」。[对话和识屏设置](codex-adapter/README.md#桌宠对话和识屏)
- **待办**打开待办提醒窗口，可查看、添加、编辑或删除事项。
- **查额度**读取本机当前登录的 Codex 账号用量，在角色的云朵气泡里显示剩余额度和重置时间。请先登录 Codex。

靠近屏幕边缘时，快捷栏会换到有空间的一侧。鼠标移开角色和快捷栏后，栏会自动收起。

### 用本机 Codex 账号对话

1. 打开 Windows 上的 Codex，确认已用 ChatGPT 账号登录。
2. 将鼠标停在 DSH 桌宠身上，点 **对话 → 完整对话 → 模型设置**。也可从桌宠右键菜单直接打开「桌宠对话」。
3. 将「对话来源」选为 **本机 Codex 账号**。Codex 模型留空时使用本机 Codex 的默认模型。点「保存」，发送一条消息测试。

完整对话与快捷对话共用这套设置，可在默认白龙、雏龙娘和大肥鱼上使用。这个模式沿用已登录的 Codex 账号和对应额度，无需填写 API Key。[Codex 接入说明](https://learn.chatgpt.com/docs/app-server#authentication-modes)

**重启桌宠后会恢复已保存的设置。**

| 设置 | 保存内容 |
| --- | --- |
| 对话来源 | 本机 Codex 账号或自定义 API |
| 本机 Codex 账号 | 选填的 Codex 模型 |
| 自定义 API | 接口地址、模型名称，以及由当前 Windows 用户加密保存并绑定到该接口的 API Key |

对话记录保存在本机。更换自定义 API 的接口地址后，可填写适用于新地址的密钥。清空 Key 并保存即可移除本机保存的密钥。[详细对话设置](codex-adapter/README.md#桌宠对话和识屏)

### 在对话里使用桌面小工具

在 DSH 桌宠上右键点「切换角色」，选 **默认白龙、雏龙娘或大肥鱼**。将鼠标停在角色身上，点「对话」，输入下列指令后按 Enter。也可以点「完整对话」，输入后点「发送」。

| 输入示例 | 桌宠会怎么做 |
| --- | --- |
| 查成都天气 | 在气泡和对话记录里显示成都当前的气温、体感、湿度和数据时间。 |
| 我还剩多少 Codex 额度？ | 读取本机当前登录的 Codex 账号，显示剩余额度和重置时间。请先登录 Codex。 |
| 工作日九点提醒我喝水 | 打开待办预览，显示事项、首次提醒时间和「工作日（周一至周五）」的重复规则。 |

确认预览后点「确认添加」，再点悬停快捷栏里的「待办」即可查看。要放弃这次待办，点「取消」。这些指令由桌宠直接处理，结果保存在本机的桌宠对话记录里。

### 使用和开发

- DSH 白龙可通过托盘或自定义全局快捷键显隐，默认组合键为 **Ctrl+Alt+P**。「桌宠设置」集中管理不透明度、播放速率、气泡字号和互动开关。「配置菜单」支持显隐、排序、自定义子菜单和实时预览。
- DSH 插件各角色使用淡紫描边的云朵气泡，文字优先显示为幼圆。气泡宽度随内容调整，长句自动换行，字号可在「桌宠设置」调整。
- 右键可新增桌宠、切换角色和管理多条待办。动画在后台解码，同素材、同速率的短待机循环可共享无损帧缓存。
- 参考 [Coopanion](https://github.com/Pal-AI-Lab/Coopanion)，DSH 白龙新增两项桌面互动：右键开启「沿屏幕底边散步」，桌宠空闲时沿当前显示器底边移动；打开「待办提醒 → 一句话添加」，输入「10分钟后提醒我喝水」或「明天上午9点提醒我开会」，核对时间后保存。两项功能均在本机运行。
- **Ctrl+Alt+J** 可打开「快捷对话」，回车发送，点回复气泡看完整对话。待办支持每天、周一至周五或每周重复，也可在到期后选择「10 分钟后再提醒」。
- 快捷对话支持按住 **F9** 或「按住说话」录音，也可以点「开始录音」和「停止录音」。Windows 在本机转成文字，检查后再发送。「桌宠对话 → 白龙记忆」可保存和编辑称呼、偏好等条目，并选择是否在聊天中使用。
- 自定义角色可使用绿幕 MP4 或透明 VP9 WebM。播放透明 WebM 需要将带 `libvpx-vp9` 的 FFmpeg 加入 PATH。
- 在 Windows 的 DSH 白龙桌宠上右键选择 **切换角色 → 大肥鱼** 即可使用随附角色包。选择「默认白龙」可切回原角色。角色包保留原有素材署名和非商业条款。[大肥鱼素材来源与许可](codex-adapter/plugins/dsh-dragon/assets/characters/大肥鱼/ASSETS.md)
- 「切换角色」也可导入本机素材文件夹或 ZIP，先预览动画，再导入并切换。「显示与播放 → 当前角色大小」可为每只桌宠的不同角色分别保存大小。
- 雏龙娘的透明动画、绿幕视频和插画源文件均随仓库提供，本机整理副本位于 `D:\Desktop\素材库\雏龙娘`。[角色包说明](materials/雏龙娘/README.md)
- 白龙的设置、对话和其他窗口会显示在桌宠前面，并优先在桌宠旁边打开。设置快捷键时，输入框显示完整组合键，格式错误或占用提示会留在设置窗口内。
- 安装了相应素材时，角色会在 Codex 思考、工作或等待确认时播放对应动画，也会按查到的剩余额度选择动作。可请 Codex 让桌宠边做动作边显示一句台词。
- 「桌面小工具」含每日一签、节日与生日提醒、整点报时和本地应用快捷启动。
- 「桌面小工具 → 查看天气」默认查询成都。气泡显示气温、体感、湿度和数据时间，连接临时失败时会重试一次。
- 「桌面灵动岛」可从右键或托盘打开，显示 Windows 正在播放的媒体、同步歌词、下一条待办和 Codex 状态。歌词可加载本地 LRC，也可主动在线查询。
- 「桌宠对话」支持流式回复、本地会话历史和 Windows 本地朗读。截图问答在确认发送前会预览选区。主动识屏需手动开启并设置应用白名单、间隔和每日上限。[对话和识屏设置](codex-adapter/README.md#桌宠对话和识屏)
- DSH 工作状态可聚合多个 Codex 会话，优先显示待确认、工作和思考。自动联动需在 Codex 的 **设置 → Hooks** 中审阅并信任。已用真实 Codex CLI 和本地模拟模型验证工具调用与任务结束时的自动触发。
- 在 Codex 新聊天中可请求启动桌宠、播放动作或显示气泡。白龙娘还支持通过桌宠菜单查询 Codex 额度。
