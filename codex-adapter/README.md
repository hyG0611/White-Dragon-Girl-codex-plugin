# 白龙桌宠合集

本项目将两套桌宠整合到同一个 Codex 本地市场和 Python 环境。

| 插件 | 功能 |
| --- | --- |
| `bailong-pet` | 25 段透明 WebP 动画、气泡、工作状态和额度展示 |
| `dsh-dragon` | MP4 绿幕播放、点击和拖拽互动、`dragon_control` 接口 |

DSH 白龙的右键菜单可锁定位置、调整不透明度和播放速率、设置自动互动间隔，以及复制当前动画画面。锁定后按住 Shift 仍可拖动。位置和播放设置会在重启后恢复。

系统托盘提供显示、隐藏、鼠标穿透和退出。隐藏时暂停动画与自动互动。右键可开启点击提示音和随机自言自语。装有「吃Token」动作时，把本地文件拖到桌宠上可触发该动画，文件留在原位。

拖动时白龙会转向，快速松手会短距离滑行。右键可启用「边缘探头」，或选择「黄金回旋」播放一圈旋转。托盘头像取自随附的白龙娘待机动画。

Windows 下可在右键菜单启用全局显隐快捷键，默认是 **Ctrl+Alt+P**。「显示与播放」可录入新的修饰键加字母或数字组合，也可设置气泡字号、自言自语台词、WAV 点击音效和多宠轻碰撞。跨屏拖动时，松手会把桌宠收回当前屏幕或最近屏幕的可用范围。

- **待办提醒**可在主桌宠右键菜单或托盘添加、编辑和删除多条事项。点「一句话添加」可输入「半小时后提醒我休息」「今晚8点提醒我开会」或「明天 09:30 提醒我交报告」。裸时刻（例如 `9点`）取下一次到达的时间；明确指定今天而时间已过时会提示修改。预览按系统本地时间显示，确认后加入现有列表，需要提前提醒时可再编辑。一次性事项到期后自动归档。错过到期时间 10 分钟以内时可补发提醒。桌宠可见时用气泡提醒，隐藏时通过托盘通知。
- **重复提醒**可在「添加」「一句话添加」或「编辑」里选每天、工作日（周一至周五）或每周。工作日选到周末会顺延至周一，每周按首次日期的星期重复。重复事项到期后自动排到下一次。到期提示后的 10 分钟内，可从托盘、右键菜单或待办列表选择「10 分钟后再提醒」，原有重复时间继续生效。
- **沿屏幕底边散步**可从右键菜单或「桌宠设置」为每只桌宠单独开启，默认关闭。空闲时桌宠先移到当前屏幕的可用区域底边，再隔一会儿移动一小段。锁定位置、隐藏、拖拽、显示气泡或 Codex 忙碌时让出控制。散步不会覆盖手动保存的位置。底边散步与一句话提醒参考 [Coopanion](https://github.com/Pal-AI-Lab/Coopanion)，均在本机运行。
- **配置菜单**可勾选显隐、拖动排序，也可将选中的条目移入同名自定义子菜单。子菜单名称留空即可移回顶层。编辑窗口会实时预览布局，点击保存后生效。
- **桌宠设置**集中管理不透明度、播放速率、自动互动间隔、气泡字号和常用互动开关。点击保存即时生效。
- **云朵气泡**用于显示自言自语、待办、Codex 状态及对话回复。文字优先使用系统幼圆，短句收窄气泡，长句自动换行。点击回复气泡可打开完整对话。
- **窗口位置**。设置、对话、待办、导入预览和文件选择等窗口会显示在桌宠前面，优先在桌宠旁边打开。空间不足时会尽量减少遮挡。截图选区仍覆盖屏幕，方便框选。
- **切换角色**可从右键选择「大肥鱼」或「默认白龙」。随附的大肥鱼角色包含 106 段透明 WebM。[素材来源与许可](plugins/dsh-dragon/assets/characters/大肥鱼/ASSETS.md)
- **雏龙娘**是独立的关键帧动画角色，完整制作提示词目录的 109 条，新版采用密集神经补帧及连续呼吸，以原生 60 fps 播放，每段 600 帧，修复初版动作头尾的长停顿与突然复位。右键「切换角色 → 雏龙娘」选择，再从「播放动作（全部素材）」手动选动作。「睡觉-开始」结束后接入「睡觉-循环」，选择「睡觉-起来」可恢复站姿。仓库附带透明视频、[绿幕 MP4 与素材索引](../materials/雏龙娘/README.md) 和 [Remotion 制作源文件](../remotion-materials/README.md)。
- **导入角色**可从「切换角色」选择素材文件夹或 ZIP。在预览窗口可切换动作、修改角色名，确认后保存到 Windows 的 `%LOCALAPPDATA%\DSHDragon\characters`。角色包最多 256 段动画、共 512 MiB，同一包内的动作需要不同的文件名。每只桌宠可通过「显示与播放 → 当前角色大小」为不同角色分别设置 50% 至 175% 的大小。
- **自定义角色**可放在 `plugins/dsh-dragon/assets/characters/<角色名>/`。待机素材可命名为 `idle` 或 `待机呼吸休闲`，也可放在 `idle` 子目录。MP4 使用绿幕处理。透明 VP9 WebM 需要支持 `libvpx-vp9` 的 FFmpeg。请将 `ffmpeg.exe` 放进本地市场的 `.runtime/Scripts/` 或加入 PATH。可运行 `ffmpeg -decoders | Select-String libvpx-vp9` 检查 PATH 版本。
- **新增桌宠**最多可同时打开八只。各自保存角色、位置和播放设置。动画在后台解码，相同素材与速率的待机动画共享解码器。循环帧采用无损压缩缓存，全部桌宠共用 96 MiB 额度。超出额度的内容继续流式解码，单次互动独立播放。透明 WebM 保留原生帧率。
- **Codex 联动**通过 `dragon_control` 的 `activity` 命令接收 `thinking`、`working`、`attention`、`idle`。多个会话同时活跃时，按待确认、工作、思考的顺序显示。一个会话结束后，其余会话的状态继续生效。Hooks 只传入事件对应的状态和用于区分会话与轮次的哈希，状态保存在内存。统一安装会生成可选 hooks，可在 Codex 的 **设置 → Hooks** 中审阅并信任。已用真实 Codex CLI 和本地模拟模型验证工具调用及会话结束时的自动联动。
- **查询 Codex 额度**可在右键菜单或托盘触发，后台通过安装时配置的 Codex 路径读取本机登录账户额度，并显示剩余百分比、重置时间和查询时间。
- **桌面小工具**可抽取每日一签，查看公历、农历节日和节气，设置公历生日提醒。节日与节气提醒、整点报时可单独开启，整点以系统提示音和气泡报时。快捷启动可选取本机 `.exe` 并从菜单打开。
- **查看天气**位于「桌面小工具」，首次打开默认填入成都。成都直接使用已知坐标，其他城市会先检索。气泡显示气温、体感、湿度和数据时间。连接临时失败时会重试一次，仅在主动查询时联网。[Open-Meteo 天气接口](https://open-meteo.com/en/docs)
- **桌面灵动岛**可从右键或托盘打开，显示下一条待办、Codex 会话状态和 Windows 当前媒体。点标题收起，点「关闭」隐藏并停止定时读取。播放器需向 Windows 系统媒体控件提供歌曲和进度。可为当前曲目加载 UTF-8 `.lrc`，也可主动点「在线找歌词」，将曲目名称、歌手、专辑和时长发给 LRCLIB 查询。切歌后清除上一曲歌词。[LRCLIB](https://lrclib.net/docs)

### 桌宠对话和识屏

- **桌宠对话**可从右键或托盘打开。在「模型设置」填写 Chat Completions 兼容接口的基础地址或完整地址，再填模型名称和服务需要的 API Key。远程地址使用 HTTPS，本机模型可用回环 HTTP。API Key 只保留在当前进程，重启后需重新输入。回复支持流式显示和停止。对话文本保存在 Windows 的 `%LOCALAPPDATA%\DSHDragon\chat-history.json`，可在窗口中切换或删除。[Chat Completions 接口](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)
- **快捷对话**默认使用 **Ctrl+Alt+J**，也可从右键或托盘打开。它使用当前模型和对话，按 Enter 发送文字，点回复气泡查看全文。右键「显示与播放」可更换或关闭全局快捷键。
- 设置快捷键时，请按住 Ctrl、Alt、Shift 或 Win，再按一个字母或数字。输入框会显示完整组合键。格式不符或已被占用时，可在原窗口查看提示并重新录入。
- **按住说话**位于快捷对话。窗口获得焦点时按住 **F9** 或按住说话按钮，等看到「正在录音」再讲话。也可以点「开始录音」，说完点「停止录音」。Windows 在本机识别并填入可编辑草稿，按 Enter 才发送文字。每段最多 30 秒，录音保留在内存，需要可用的默认麦克风和支持听写的 Windows 本地识别语言。[Windows 本地语音识别](https://learn.microsoft.com/en-us/dotnet/api/system.speech.recognition.speechrecognitionengine?view=netframework-4.8)
- **白龙记忆**位于完整聊天窗口。可直接添加、编辑或删除条目，也可在历史里选中文字，点「记住选中内容」后确认保存。记忆保存在本机设置中。只有勾选「在聊天请求中使用这些记忆」后，普通和快捷对话才会把条目随请求发给当前配置的模型。
- **朗读回复**在对话窗口单独开启，使用 Windows 本地语音。关闭窗口或点击「停止」可中止朗读。
- **截图问答**从右键或托盘进入。先配置支持图片输入的模型，再在鼠标所在屏幕框选。松手后可在对话窗口预览，按 Esc 可放弃框选。点击「发送」才会提交预览图片，聊天历史只保存问答文本。
- **主动识屏**默认关闭。先在右键的「主动识屏 → 识屏设置」选择允许读取的应用，并设置最短间隔和每日上限，再确认开启。当前台停留在白名单应用时，桌宠会尝试获取该窗口内容并用模型回复气泡。切换模型地址、修改白名单或重启桌宠都需要重新开启。隐藏桌宠时暂停，本地历史不保存主动识屏截图。

### 安装与启动

在本目录运行以下命令。首次安装需要提供可信的 Python 3.11+ 绝对路径，Python 需包含 Tk。

```powershell
.\install.ps1 -PythonPath 'D:\python\python.exe'
```

更新已有安装时重新运行安装脚本，以安装 Windows 媒体读取依赖。

默认在 `bailong-local` 下安装两个插件。可用 `-Plugins bailong-pet` 仅安装白龙娘，也可用 `-VideoSource 'D:\Desktop\素材库'` 导入额外的 DSH MP4。仓库随附 DSH 待机视频。若已有同名市场指向旧目录，请在 Codex 插件管理中移除旧市场登记后重新运行安装。

`setup.ps1` 仅创建共享环境和生成插件配置。统一安装入口更新 Windows 登录启动项中的 DSH Dragon Codex 快捷方式。一个后台监控负责启动所选桌宠。打开 Windows Store 版 Codex 时启动，Codex 完全退出时关闭。手动退出桌宠后，下次打开 Codex 才会再次自动启动。若旧版监控仍在运行，注销并重新登录 Windows 后切换到新版。白龙娘工作状态 hooks 由 Codex 的信任流程管理。

白龙娘的操作和素材许可见 [BAILONG.md](BAILONG.md) 和 [ASSETS.md](plugins/bailong-pet/ASSETS.md)。

```powershell
.\.runtime\Scripts\python.exe -m unittest discover -s tests -v
```
